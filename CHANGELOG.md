# Changelog

All notable changes to this kit are documented here. The format follows Keep a Changelog, and the project uses semantic versioning.

## [0.1.0] - 2026-11-08

### Added

- `CONTRACT.md`: 14 generic hard rules with one-line rationales.
- `hooks/inject-contract.sh`: POSIX `sh` SessionStart hook that re-injects the contract and counts logged drifts, with a sample `settings.json` and a hooks README.
- `memory/drift-log.md`: drift log format and three invented example entries.
- `commands/rodin.md`: anti-complacency sparring command.
- Skills: `verify-frontend-change` and `regulated-communication`.
- Templates: `CLAUDE.md.template` (with the 20/80 frame) and `goal-template.md` (convergence check).
- `docs/ai-code-gate.md`: one-page design of a CI gate for agent-written code.
